Механическую работу
ВСЕГДА совершает конкретная сила F

Под действием этой силы или против неё тело перемещается.

Как посчитать механическую работу?

Работа равна силе, умноженной на пройденный путь:

A = F · s

1. Сила помогает движению

Сила толкает тело в ту же сторону, куда оно движется (разгон санок). Работа силы — положительная.

Работа A = 0 Дж (A > 0)

2. Сила мешает движению

Сила направлена против движения (сила трения при торможении). Работа силы — отрицательная.

Работа A = 0 Дж (A < 0)

3. Сила действует под углом

Тянем чемодан за ручку косо вверх и вперед. В работу засчитывается только та часть силы, которая помогает ехать вперед!

Работа A = 0 Дж (A > 0)

4. Сила перпендикулярна движению

Несем портфель строго вверх, а движемся вперед. Сила не помогает и не мешает движению по горизонтали. Её работа равна НУЛЮ.

Работа A = 0 Дж (A = 0)

5. Вертикальный подъем груза

Мы поднимаем груз вертикально вверх. Сила тяги направлена вверх, и перемещение идет вверх. Работа нашей силы — положительная (мы преодолеваем тяжесть Земли!).

Работа A = 0 Дж (A > 0)

6. Движение по инерции

Тело скользит по идеальной поверхности. Трения нет, тянущей силы тоже нет. Перемещение есть, но сила F = 0. Работа равна НУЛЮ.

Работа A = 0 Дж (A = 0)

Проверка знаний. Ситуация 1

Ученик изо всех сил толкает тяжелый шкаф, но шкаф не сдвинулся с места. Совершил ли ученик механическую работу с точки зрения физики?

Да, конечно! Ведь он сильно устал.
Нет. Сила была приложена, но перемещения тела нет (s = 0), значит работа равна 0.
Работа совершена, но она отрицательная.

Проверка знаний. Ситуация 2

Школьник несёт портфель в руке по горизонтальной дороге. Совершает ли работа силы руки, удерживающей портфель, механическую работу?

Да, совершает положительную работу.
Нет, сила руки направлена вверх, а движение идет вперед (90°). Сила не помогает движению.
Да, совершает отрицательную работу.
